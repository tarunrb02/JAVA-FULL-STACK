STORED PROCEDURES:

IT IS A PROCEDURE IN WHICH SET OF QUERIES ARE STORED  IN THE DATABASE AND WHENEVER  WE WANT TO EXECUTE THE QUERIESS, JUST CALL THE PROCEDURE ALOG WITH THE PARAMETER

	DELIMITER $$     / WE ARE CHNGING THE TERMINATION SYMBOL FOR A WHILE TO WRITE PROCEDURE SINCE POCEDURES ARE CONTAINING MULTIPLE QUERIES WITH ';' SO....
		
	SYN:	DELIMITER $$
		CREATE PROCEDURE PROCEDURE_NAME()
		BEGIN
		SQL QUERIES 
		END $$

		DELIMITER ;

		DELIMITER $$
		CREATE PROCEDURE PROCEDURE_NAME(IN VAR_1 DATATYPE, VAR_2 DATATYPE)
		BEGIN
		SQL QUERIES 
		END $$

		DELIMITER ;

	+ CALL PROCEDURE PROCEDURE_NAME(PARAMETER) // TO CALL PROCEDURE

	+ DROP PROCEDURE PROCEDURE_NAME;   // DROP THE PROCEDURE
	+ SHOW CREATE PROCEDURE PROCEDURE_NAME;  // SHOWS THE STRUCURE/IMPLEMENTAION OF PROCEDURE
	+ SHOW PROCEDURE STATUS WHERE DB=DB_NAME;  // LIST ALL PROCEDURE IN DB

	CREATE PROCEDURE UPDATESALARY(IN A INT, B INT)
    	BEGIN
    	UPDATE EMP_LOG SET SALARY= SALARY+(SALARY * B/100) WHERE E_ID= A;
