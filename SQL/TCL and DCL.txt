TCL: IT IS LANGUAGE WHICH IS USED TO CONTROL OVER SET OF QUEIRIES

COMMANDS:

	1. COMMITS: IT IS USED TO SAVE THE CHANGES PERMANENTLY
               	SET AUTOCOMMIT = 1; ------ON
               	SET AUTOCOMMIT = 0; ------OFF

	2. ROLLBACK: IT IS USED TO UNDONE THE CHANGES
               	SYS : ROOLBACK;

	3. SAVEPONT : ARE THE CHECKPOINTS USED TO UNDONE THE CHANGES UPTO THE SPECIFIC POINTS
        	SYS: SAVEPOINT S1;
                     SAVEPOINT S1;

DCL: DATA CONTROL LANGUAGE (CASE SENSITIVIE)

	1. GRANT: IT IS USED TO GIVE THE ACCESS/ PRIVILAGE TO USER
		GRANT (TYPE OF ACCESS) ON DATABASE.* TO 'USERNAME@LOCALHOST';

	2. REVOKE: IT IS USED TO TAKE BACK THE ACCESS/ PRIVILAGE FROM USER

SOME IMPORTENT QUERIES:
	SELECT CURRENT_USER;

	SELECT USER,HOST FROM MYSQL.USER;

	CREATE USER 'USERNAME@LOCALHOST' IDENTIFIED BY 'PASSWORD'; ----- TO C REATE THE USER

	DROP USER 'USERNAME@LOCALHOST'; -----TO REMOVE THE USER
	
	SHOW GRANTS FOR 'USERNAME@LOCALHOST'; ---DESCRIBE THE PERMISSION ON SPECIPIC USER

	GRANT ALL PRIVILEGES ON ORG.* TO 'test'@'localhost';

	REVOKE ALL PRIVILEGES ON ORG.* FROM 'test'@'localhost';
