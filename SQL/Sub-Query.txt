
SUB QUERE: A SUBQUERY IS A QUERY WHICH IS NESTED INSIDE ANOTHER QUERY.
+ THE SUBQUERY MUST RETURN ONLY ONE COLUMN, UNLESS IT IS BEING USED WITH THE EXISTS OPERATOR. 

+ HE DATA YOUR SUBQUERY RETURNS MUST MATCH WHAT THE OUTER QUERY OPERATOR EXPECTS. 

+ SINGLE VALUE CONDITION (SCALAR): IF YOU USE BASIC COMPARISON OPERATORS (=, >, <, !=), YOUR SUBQUERY MUST RETURN EXACTLY ONE COLUMN AND ONE ROW. 

+ LIST CONDITION (MULTIPLE ROWS): IF YOUR SUBQUERY RETURNS MULTIPLE ROWS OF DATA, YOU MUST USE LIST OPERATORS LIKE IN, NOT IN, ANY, OR ALL. 

EXAMPLE:
	SELECT * FROM EMP_LOG WHERE DEPT_ID IN (SELECT DEPT_ID FROM EMP_LOG GROUP BY DEPT_ID HAVING AVG(SALARY)>50000);

	SELECT * FROM EMP_LOG WHERE SALARY= (SELECT SALARY FROM EMP_LOG WHERE FNAME='RAM');

TYPES OF SUBQUERY
1. SINGLE ROW SUBQUERY
2. MULTI ROW SUBQUERY
3. CORRELATED SUBQUERY

1. SINGLE ROW SUBQUERY: A SUBQUERY WILL RETURNS ONLY SINGLE VALUE
	Q1. DISPLAY THE EMP DETAILS WHO ARE EARNING MORE THAN AFFAN
	    SELECT * FROM EMP_LOG WHERE SALARY>(SELECT SALARY FROM EMP_LOG WHERE FNAME='AFFAN');
	
	Q2. DISPLAY THE EMP DETAILS WHO IS GETTING MAXIMUM SALARY
	    SELECT * FROM EMP_LOG WHERE SALARY=(SELECT MAX(SALARY) FROM EMP_LOG);

	Q3. DISPLAY THE EMP DETAILS WHO IS WORKING IN THE SAME DEPARTMENT OF VARUN
	    SELECT * FROM EMP_LOG WHERE DEPT_ID=(SELECT DEPT_ID FROM EMP_LOG WHERE FNAME='VARUN'); 

	Q4. DISPLAY THE EMP DETAILS WHO IS EARNING MORE THAN AVG SALARY FROM DEPARTMENT 101
	    SELECT * FROM EMP_LOG WHERE SALARY>(SELECT AVG(SALARY) FROM EMP_LOG) AND DEPT_ID=101;

	Q5. DISPLAY THE EMP DETAILS WHO IS  NOT WOKING IN THE SAME DEPT AS SAHANA
	    SELECT * FROM EMP_LOG WHERE DEPT_ID !=(SELECT DEPT_ID FROM EMP_LOG WHERE FNAME='SAHANA');

	Q6. DISPLAY THE EMP WHO BELONGS TO SAME DEPARTMENT S SURYA AND EARING MORE THAN SURYA
	    SELECT * FROM EMP_LOG WHERE DEPT_ID=(SELECT DEPT_ID FROM EMP_LOG WHERE FNAME='RAM')
    	    -> AND SALARY>
    	    -> (SELECT SALARY FROM EMP_LOG WHERE FNAME='RAM');

	Q7. DISPLAY THE EMP WHO ARE HAVING THE SAME AGE OF SHRAVAN
	    SELECT * FROM EMP_LOG WHERE E_AGE=(SELECT E_AGE FROM EMP_LOG WHERE FNAME='RAM');
	
	Q8. DISPLAY THE EMP DETAILS WHO LOCATION IS NOT SAME AS BENGALURU
	    SELECT * FROM EMP_LOG WHERE EMP_LOCATION != 'BENGALURU';

	Q9. DISPLAY THE EMP DETAILS WHO IS YOUNGER THAN RAM
	SELECT * FROM EMP_LOG WHERE E_AGE<(SELECT E_AGE FROM EMP_LOG WHERE FNAME='RAM');

2. MULTI ROW SUBQUERY: A SUBQUERY WHICH RETURNS MORE THAN ONE VALUE TO THE OUTER QUERY.

	Q1. DISPLAY THE EMP DETAILS WHO BELONGS TO DEPARTMENT 101 AND 102
	    SELECT * FROM EMP_LOG WHERE DEPT_ID IN (SELECT DEPT_ID FROM EMP_LOG WHERE DEPT_ID=101 OR DEPT_ID=102);
