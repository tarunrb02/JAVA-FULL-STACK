--------------------inline vs block -----------------------------
inline level element: * width occupied is only as much of element size
                    * these element displayed in the same line 
                    * it will tack content height and width
                    * ex: span, input tag, anchor tag

block level element: * width occupied is up to complete screen
                    * these element displayed in the next line 
                    * it will tack content height and full width of screen or parent element
                    * div, h1-h6, p tag

# HTML `<form>` Attributes
The `<form>` element is used to collect user input and send it to a server.

## Syntax:
<form action="/submit" method="post">
    <!-- Form elements -->
</form>

# 1. `action`
Specifies **where the form data will be sent** after the user clicks the Submit button.

Syntax:
<form action="/login">

Example
<form action="index.html">

If omitted:

```html
<form>
The form submits to the **current page**.

# 2. `method` :Specifies **how the data is sent**.
### Values:
    * `get`
    * `post`

### Example:
<form method="get">
    or
<form method="post">

### GET
-------
* Data is appended to the URL.
* Used for searching.
* Limited data size.
* Data is visible.
Example: search.html?name=Tarun

### POST
---------
* Data is sent in the request body.
* Better for passwords and sensitive data.
* Can send large amounts of data.

# 3. `target`: Specifies **where the response will open**.
### Values: 
| Value     | Description                 |
| --------- | --------------------------- |
| `_self`   | Opens in same tab (default) |
| `_blank`  | Opens in new tab            |
| `_parent` | Opens in parent frame       |
| `_top`    | Opens in full window        |

### Example
<form target="_blank">

# 4. `autocomplete`: Controls whether the browser should remember previously entered values.
### Values:
* `on`
* `off`

### Example:
<form autocomplete="on">
        or
<form autocomplete="off">

# 5. `novalidate`: Disables browser validation.
Normally: <input type="email" required>
+ The browser checks if the email is valid.

With: <form novalidate>
No validation occurs.

# 6. `name`: Assigns a name to the form.
<form name="studentForm">
Can be accessed in JavaScript.

```javascript-
document.forms["studentForm"]
```
# 7. `id`: Provides a unique identifier.
<form id="loginForm">
Useful for CSS and JavaScript.

```javascript
document.getElementById("loginForm")
```
# 8. `onsubmit`: Executes JavaScript before submitting the form.
<form onsubmit="return validate()">
If the function returns:
* `true` → Form submits.
* `false` → Submission is cancelled.

# Complete Example:
------------------
<form
    action="/register"
    method="post"
    target="_blank"
    autocomplete="on"
    id="registerForm"
    name="registerForm"
    onsubmit="return validate()"
>
    <input type="text" name="name">
    <input type="email" name="email">
    <input type="file" name="photo">
    <input type="submit">
</form>

# Quick Revision Table
-----------------------------------------------------------
| Attribute        | Purpose                               |
| ---------------- | --------------------------------------|
| `action`         | URL where form data is sent           |
| `method`         | HTTP method (`GET` or `POST`)         |
| `target`         | Where the response opens              |
| `autocomplete`   | Enable or disable browser autofill    |
| `novalidate`     | Disable browser validation            |
| `name`           | Name of the form                      |
| `id`             | Unique identifier for CSS/JavaScript  |
| `onsubmit`       | Run JavaScript before submission      |
